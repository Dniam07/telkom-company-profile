# Telkom University Company Profile - Praktikum

Project simulasi HTML, CSS, PHP native, MySQL/MariaDB, dan Git.

## Cara Menjalankan Project

1. Simpan folder project di `C:\laragon\www\telkom-company-profile`.
2. Jalankan **Apache** dan **MySQL** melalui Laragon.
3. Import file `database/telkom_profile.sql` melalui phpMyAdmin.
4. Buat file `.env` di folder utama project dengan isi seperti yang ada di dalam .env.example:
5. Buka project melalui browser:
```text
http://localhost/telkom-company-profile/
```
